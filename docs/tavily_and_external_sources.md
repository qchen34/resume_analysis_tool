# Tavily 搜索优化与外部数据源调研

本文档记录：Tavily 检索的优化方式，以及脉脉、猎聘、Boss 等求职/招聘数据源的开放能力与可行性。

---

## 一、Tavily 当前优化（已实现）

- **查询构造**：在 `src/analysis/tavily_search.py` 中，按查询类型使用不同模板，并加入约束词以提升与招聘/求职的相关性：
  - 公司介绍：增加「招聘」；
  - 岗位职责：增加「招聘」「岗位」「任职要求」；
  - 面试经验：增加「面试」「面经」「高频问题」；
  - 行业趋势：增加「招聘」「人才需求」。
- **结果过滤**：对 Tavily 返回的 `answer` 摘要做关键词过滤；若摘要中不包含预设关键词（招聘、求职、面试、岗位、公司、JD、简历、职位、面经、offer、入职）之一，则替换为提示文案，避免无关内容进入报告。可通过环境变量 `TAVILY_FILTER_RESULTS=false` 关闭过滤。
- **后续可做**：使用 LLM 对单条摘要做一句话相关性判断，再决定是否保留（会增加调用成本与延迟）。

## 二、外部数据源调研结论

以下为公开信息与常见合作模式的整理，**不构成法律或合规建议**；接入前需自行确认各平台最新条款与 API 政策。

| 平台 | 开放 API | 说明与可行性 |
|------|----------|--------------|
| **脉脉** | 未提供面向个人/第三方的开放招聘 API | 数据主要通过 App/网页端使用，无公开文档的招聘数据接口；若需数据需联系商务/企业合作。 |
| **猎聘** | 未提供面向个人/第三方的开放招聘 API | 企业端有招聘管理相关能力，不面向普通开发者开放；无公开的「岗位/面试经验」查询 API。 |
| **Boss 直聘** | 未提供面向个人/第三方的开放招聘 API | 岗位与沟通数据均属平台核心资产，无公开 API；爬虫抓取违反服务条款且存在法律与封禁风险。 |
| **拉勾 / 智联 / 前程无忧** | 未提供通用开放 API | 与上类似，招聘数据不对外开放；企业客户有内部系统对接，非通用开放。 |

**结论**：当前无法依赖脉脉、猎聘、Boss 等平台的开放 API 获取招聘/求职数据。**现阶段方案**为：继续使用 Tavily 等通用搜索接口，通过优化查询构造与结果过滤（见上文）提高与「公司介绍、岗位要求、面试经验、行业趋势」的相关性；若未来与某平台达成正式合作，再在本文档中补充对接方式与数据格式说明。

## 三、相关配置

| 变量 | 说明 |
|------|------|
| `TAVILY_API_KEY` | Tavily API 密钥；未配置则仅生成查询计划，不发起请求。 |
| `TAVILY_FILTER_RESULTS` | 是否对摘要做关键词过滤（默认 `true`）；设为 `false` 可保留原始摘要。 |
