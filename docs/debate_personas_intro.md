代码中可用（见 `src/llm/debate_personas.py`）：

- `get_intro(persona_id)`：单个人物简介字符串
- `get_intros_for_llm(persona_ids)`：多个人物简介拼成一段文本，便于注入 prompt
- `get_intros_as_dict(persona_ids)`：返回 `[{ id, display_name, category, intro }, ...]`，可 `json.dumps` 后存为 JSON 或传给 LLM
